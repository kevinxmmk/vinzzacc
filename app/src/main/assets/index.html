Generator acapella

Bikin lagu baru 4 suara (lead, alto, tenor, bass) dari tangga nada dan progresi chord. Hasilnya menggantikan semua track, bisa diurungkan.

Ekspor

WAV dan MIDI tersimpan di versi APK atau file HTML. Dari pratinjau Claude, hanya proyek .json dan teks not yang bisa disimpan.

Cara pakai cepat
  1. Tab MIDI: muat contoh, impor file .mid, atau buat lagu lewat generator.
  2. Tab Piano roll: pilih track di chip warna, lalu pakai alat Gambar (ketuk kotak kosong untuk menaruh not, seret ke kanan untuk memanjangkan), Pindah (seret not, tarik ujung kanannya untuk mengubah panjang), Hapus (ketuk not).
  3. Alat Geser dipakai untuk scroll roll dengan jari. Di alat lain, scroll dimatikan supaya gambar tidak meleset.
  4. Ketuk penggaris di atas untuk menaruh titik mulai. Ketuk tuts di kiri untuk mendengar nadanya.
  5. Tab Suara: atur vokal (A E I O U), vibrato, layering, napas, reverb.
Bikin suara mirip vokal
  • Gelombang: sumber suaranya sawtooth. Kaya harmonik, jadi filter vokal punya bahan untuk dibentuk.
  • Formant: tiga filter band-pass paralel meniru bentuk mulut. Ganti A/E/I/O/U buat ganti warna vokal.
  • Vibrato: LFO ±5 Hz ke pitch, masuk perlahan setelah not mulai. Depth 10–25 cent terdengar natural.
  • Layering: beberapa sawtooth dengan detune tipis (5–12 cent) bikin kesan banyak penyanyi.
  • Napas: noise tipis lewat filter formant yang sama.
  • Reverb: hall sekitar 2,5 detik. Mix 20–30% cukup untuk acapella.

Pakai di Harmor (FL Studio)

Harmor adalah plugin FL Studio, jadi tidak ada di app ini. Alurnya:

  1. Simpan MIDI dari tab MIDI, lalu seret ke Playlist atau Piano roll FL Studio (File → Import → MIDI file).
  2. Pasang satu Harmor per track. Di tab IMG, buka sample acapella (WAV), aktifkan resynthesis.
  3. Atur Pitch supaya mengikuti not, dan Formant supaya suara tidak jadi "chipmunk" saat not digeser jauh.
  4. Tambah Unison di tab MAIN untuk layering, lalu reverb di mixer.

Nama menu bisa beda antarversi FL Studio.

Batasan
  • Tidak ada resynthesis sample seperti Harmor. Suara dibuat dari synth vokal bawaan.
  • Impor MIDI hanya memakai tempo pertama di file. Perubahan tempo di tengah lagu diabaikan.
  • Not yang bertumpuk di nada yang sama saat diputar bisa terdengar menebal.
  • Latency audio browser lebih tinggi daripada DAW desktop. Cocok untuk menyusun, bukan untuk rekam langsung.
